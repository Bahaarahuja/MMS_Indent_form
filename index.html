MMS Indent Builder Guide

How to use the MMS form

  • Select MMS Indent Form and upload all required workbooks.
  • Click Build preview and review counts, language groups, remarks, colors, and exceptions.
  • Enter Qty only in editable cells. Grey Out of Stock Qty cells are blocked.
  • Download Main Excel and Exception Excel after review.

Where Books data comes from

  • Books Master: Language, Language Category / Laguage Category, MMS Code, Book Name / Title, BAV Code, Short Code, Identity, Sale Price, and Cost Price.
  • Books Stock Position Report: matched to Books Master using MMS Code. Excel column V is Total HQ DL Stock. Excel column AM is PB HQ + Dera Stalls.
  • Combined Stock: Books Stock Position column V (Total HQ DL Stock) + column AM (PB HQ + Dera Stalls).
  • SOSRC workbook: SOSRC Book List, Column C Identity, matched to Books Master Identity.
  • Previous Indent: BOOKS tab CODE column; its first 8 characters are used for exception comparison.

Dynamic language logic

The builder reads Language and Language Category / Laguage Category directly from Books Master. Languages are not hardcoded. MMS includes every non-Foreign category, including new categories added later.

Books stock logic

  • Out of Stock: Books Stock Position column V (Total HQ DL Stock) + column AM (PB HQ + Dera Stalls) < 10.
  • English/Hindi/Punjabi: All India if Combined Stock < 100; otherwise DL if Books Stock Position column V (Total HQ DL Stock) < 100.
  • Every other non-Foreign category: All India if Combined Stock < 30; otherwise DL if Books Stock Position column V (Total HQ DL Stock) < 30.
  • Foreign: no stock thresholds until rules are confirmed.

Color logic

  • Grey: Out of Stock. Qty is blocked and amounts remain zero.
  • Light green: All India low stock.
  • Light brown: DL low stock.
  • Light peach: SOSRC only. SOSRC text is blue and italic.
  • Light blue: no remark/default row.

Color priority: Grey Out of Stock > Light green All India > Light brown DL > Light peach SOSRC-only > Light blue default.

SOSRC and exceptions

SOSRC Book List Column C Identity is matched to Books Master Identity. Exceptions are generated books whose short code is not found in the previous BOOKS tab.

MMS form का उपयोग

  • MMS Indent Form चुनें और सभी आवश्यक workbooks अपलोड करें।
  • Build preview पर क्लिक करके counts, language groups, remarks, colors और exceptions जाँचें।
  • केवल editable Qty cells में मात्रा भरें। Grey Out of Stock Qty cells locked रहते हैं।
  • जाँच के बाद Main Excel और Exception Excel डाउनलोड करें।

Books का data कहाँ से लिया जाता है

  • Books Master: Language, Language Category / Laguage Category, MMS Code, Book Name / Title, BAV Code, Short Code, Identity, Sale Price और Cost Price।
  • Books Stock Position Report: MMS Code से Books Master से match किया जाता है। Excel column V = Total HQ DL Stock और Excel column AM = PB HQ + Dera Stalls।
  • Combined Stock: Books Stock Position का column V (Total HQ DL Stock) + column AM (PB HQ + Dera Stalls)।
  • SOSRC workbook: SOSRC Book List का Column C Identity, Books Master के Identity से match होता है।
  • Previous Indent: BOOKS tab का CODE column; पहले 8 characters exception comparison के लिए उपयोग होते हैं।

Dynamic भाषा logic

Builder, Books Master के Language और Language Category / Laguage Category columns सीधे पढ़ता है। Languages hardcode नहीं हैं। MMS में हर non-Foreign category अपने-आप शामिल होती है।

Books stock logic

  • Out of Stock: Books Stock Position column V (Total HQ DL Stock) + column AM (PB HQ + Dera Stalls) < 10।
  • English/Hindi/Punjabi: Combined Stock < 100 होने पर All India; अन्यथा Books Stock Position column V (Total HQ DL Stock) < 100 होने पर DL।
  • अन्य सभी non-Foreign categories: Combined Stock < 30 होने पर All India; अन्यथा Books Stock Position column V (Total HQ DL Stock) < 30 होने पर DL।
  • Foreign: rules confirm होने तक stock thresholds लागू नहीं हैं।

Color logic

  • Grey: Out of Stock। Qty locked रहता है और amounts zero रहते हैं।
  • Light green: All India low stock।
  • Light brown: DL low stock।
  • Light peach: केवल SOSRC। SOSRC text blue italic में दिखता है।
  • Light blue: कोई remark नहीं / default row।

Color priority: Grey Out of Stock > Light green All India > Light brown DL > Light peach केवल SOSRC > Light blue default।

SOSRC और Exception List

SOSRC Book List के Column C की Identity को Books Master की Identity से match किया जाता है। Exception List में वे generated books आती हैं जिनका short code previous BOOKS tab में नहीं मिलता।
